# SHINRA — план обучения итерациями + чеклист подъёма Blackwell

Дата: 30-09-2026. Статус: утверждено частично, три решения открыты (§5).
Завтра днём: совместный подъём Blackwell с Magой.

## 0. Зафиксированные решения

- Student: SHINRA full-parameter (собственные веса, архитектура, tokenizer Unigram 131072). LoRA не используется.
- Учителя: Qwen3 Apache-2.0 dense (EN/RU/код) + DeepSeek-R1 MIT (математика, reasoning-следы переписываются в связный текст).
- Исключены: Llama ≤3.0 (запрет обучения других LLM на выходах), Llama ≥3.1 (требует префикс «Llama» — конфликт с именем/инвариантом), proprietary API без юрпроверки.
- Лицензии проверены 29-09-2026 (веб): Qwen3 open weights — Apache 2.0 (конкретный релиз перепроверить, семейство 2026 разъехалось); R1 — MIT.
- Пилот D0: 5M honest-токенов на рукав, T (teacher 75/25 EN/RU) vs N (natural).
- Фаза 1 — только тексты (дистилляция распределений отложена: разные словари, нужен отдельный механизм).
- Учитель пишет ДОКУМЕНТЫ, не чаты (pretrain-DNA).

Выше ~1B на одной карте — отдельное решение, не default.

## 2. Этапы

### D0 — пилот сравнения (5M/рукав)
Старт обоих рукавов: random-init (предложение; альтернатива — оба от C489, см. §5).
Гейты: `heldout_ce` EN/RU раздельно (победа — §5), нет NaN, UNK/повторы сравнением.
Провал T → teacher-рецепт закрыт, идём natural-линией.

### D1 — масштабирование победителя (потолок — §5, предложение 50M)
Random-init, один прогон. Гейты: монотонный held-out к концу, разрыв с D0-бейзлайном,
генерация без деградации. Плоские кривые = чинить pipeline (LR/batch/маски), не данные.

### D2 — языковая база (250M → 1B по решению)
Состав: teacher-поколение-2 (по провалам D1) + natural + первые code-документы с тестами.
Пропорции фиксируются до старта. Гейты: EN/RU held-out, компилируемость кода,
сверка мат-ответов на закрытом наборе.

### D3 — инструктивная линия (только после живой D2)
SFT (chat-формат впервые легален), затем DPO. SFT на немой базе запрещён.

## 3. Сквозные правила

1. Один изменяемый фактор за прогон.
2. Baseline до первого update; mid/final — гейтами барабана (вшиты в код).
3. Closed-наборы (held-out, пробы) — никогда в обучение; бенчмарк-решения — вне корпуса.
4. Resolved-конфиг + receipts у каждого checkpoint, иначе прогон не считается.
5. Лимит units на этап — до старта; исчерпание = стоп и разбор.
6. Стоп-счётчик: legacy-honest; `counter-v1` параллельно.
